# Chess Academy

Русскоязычная PWA-основа шахматной академии для Android и настольных браузеров.

## Запуск
После включения GitHub Pages открой сайт репозитория. На Android в Chrome можно выбрать «Добавить на главный экран».

## Реализовано в текущей сборке
- Адаптивный русскоязычный интерфейс.
- Шахматная доска с легальными ходами, рокировкой, взятием на проходе и превращением пешки в ферзя.
- Отмена хода, переворот доски и новая партия.
- Импорт PGN, экспорт текущей партии и локальное сохранение партий.
- Справочные карточки пяти дебютов и пяти тактических мотивов.
- PWA manifest и кэширование оболочки сайта.

## Пока не реализовано
Stockfish, глубокий компьютерный анализ, игра против движка, проверенные интерактивные тактические задачи, полные PGN знаменитых партий и гарантированная полностью офлайн-работа. Поэтому эту сборку нельзя считать гроссмейстерским анализатором. Библиотека правил chess.js загружается с esm.sh и требует интернет при первом запуске.
