# Chess Academy

Русскоязычная PWA для шахматной практики на Android и в браузере.

## Что работает сейчас

- Адаптивный интерфейс на русском языке.
- Шахматная доска и легальные ходы через chess.js: рокировка, взятие на проходе, превращение пешки в ферзя.
- Режим игры против встроенного локального соперника с тремя уровнями поиска. Это простой minimax-поиск с оценкой материала и базовых позиционных факторов, не Stockfish и не гроссмейстерский анализатор.
- Импорт PGN, пошаговое перемещение по загруженной партии, экспорт текущей партии и локальное сохранение.
- Карточки дебютов и краткие справки по тактическим мотивам.
- Мини-тест по дебютным принципам и шахматным правилам.
- Локальная статистика занятий.
- PWA manifest и кэширование оболочки сайта.

## Что ещё не реализовано

- Stockfish NNUE и полноценный глубокий анализ с вариантами и оценкой качества каждого хода.
- Проверенная большая база тактических задач с рейтингом сложности.
- Полная PGN-библиотека известных партий с комментариями и обучающими вариантами.
- Локальная поставка chess.js и движка: сейчас chess.js загружается с esm.sh, поэтому первый запуск требует интернет, а полностью автономная работа пока не гарантируется.
- Облачная синхронизация профиля. Сохранения находятся только в локальном хранилище браузера.

## Публикация

В GitHub открой Settings → Pages → Build and deployment → GitHub Actions. После успешного запуска workflow сайт будет доступен по адресу https://kach0ta.github.io/Chess-Academy/.

На Android открой сайт в Chrome и выбери «Добавить на главный экран».
