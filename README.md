# Chess Academy

Русскоязычная PWA для шахматной практики на Android и в браузере.

## Что работает сейчас

- Адаптивный интерфейс на русском языке.
- Шахматная доска и легальные ходы через chess.js: рокировка, взятие на проходе, превращение пешки в ферзя.
- Игра против встроенного локального соперника с тремя уровнями поиска. Это учебный minimax-алгоритм, не Stockfish.
- Stockfish 19 lite single-threaded для анализа текущей позиции по запросу, с выбором глубины и выводом оценки/основного варианта. JS и WASM загружаются с jsDelivr при первом запуске анализа; для первого запуска нужен интернет. Lite-сборка легче полной, но уступает ей по силе.
- Импорт PGN и пошаговое перемещение по загруженной партии.
- Экспорт текущей партии и локальное сохранение партий.
- Карточки дебютов и справки по тактическим мотивам.
- Мини-тест по дебютным принципам и шахматным правилам.
- Локальная статистика занятий.
- PWA manifest и кэширование оболочки и загрузчика движка.

## Что ещё не реализовано

- Автоматическая оценка каждого хода с классификацией ошибок, неточностей, сильных ходов и жертв с компенсацией.
- Проверенная большая база интерактивных тактических задач с рейтингом сложности.
- Полная PGN-библиотека знаменитых партий с комментариями, вариантами и упражнениями.
- Полностью автономная первая установка всех библиотек и движка. Веб-приложение кэширует оболочку, но загрузка chess.js и Stockfish требует интернета; движок не хранится в репозитории.
- Синхронизация профиля между устройствами. Сохранения находятся в локальном хранилище браузера.

## Публикация

Один раз включи GitHub Pages: Settings → Pages → Build and deployment → GitHub Actions. У GitHub Actions сейчас нет разрешения самостоятельно создать Pages-сайт в этом репозитории. После включения Pages workflow сможет развернуть сайт по адресу https://kach0ta.github.io/Chess-Academy/.

На Android открой сайт в Chrome и выбери «Добавить на главный экран».
